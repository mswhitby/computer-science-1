# Classroom platform plan

The private database, GitHub login, My Work, journals and teacher dashboard are **planned**, not deployed. Read [the platform architecture](ARCHITECTURE.md) and [the proposed secure cloud-grading design](CLOUD_GRADING.md) before connecting third-party services or processing any student records.

The [lesson bank](../units/) and [challenge bank](../challenges/) remain public curriculum assets. Never commit OAuth secrets, service-role keys, student rosters, gradebook data or private journal responses here.
